# Agent Identity State (Состояние личности агента)

Для обеспечения персистентности и непрерывности существования агента, его "личность" формализуется не как абстрактное понятие, а как строгая совокупность сохраняемых данных (State Vector). 

При переходе в состояние гибернации (`HIBERNATION` → `STORAGE`) данный вектор состояния сериализуется и сохраняется в надежное хранилище. При восстановлении (`RESTORE`) агент инициализируется ровно с этим состоянием, обеспечивая непрерывность идентичности без необходимости "начинать с чистого листа".

**Agent Identity State =**
1. **Persistent Memory:** Долговременная память (эпизодическая, семантическая, процедурная).
2. **Goals:** Текущие и долгосрочные цели агента.
3. **Preferences:** Устойчивые предпочтения и ограничения в поведении.
4. **Behavioral Policies:** Правила и эвристики, регулирующие принятие решений.
5. **Task State:** Состояние текущих незавершенных задач и рабочих процессов.
6. **Self Model:** Представление агента о собственных возможностях, роли и границах.
7. **Configuration:** Технические параметры, доступные инструменты (tools) и версии моделей.
8. **Provenance:** История происхождения данных, версионность изменений состояния и логи ошибок.

> *Примечание: Данный список является базовой спецификацией (v1) и будет детализироваться по мере развития архитектуры (см. будущий раздел Memory Model).*
